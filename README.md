# Customer Funnel & Conversion Performance Analysis

## 📊 Project Overview
This project focuses on analyzing user behavior across a marketing funnel to understand conversion patterns and identify drop-off points. The analysis helps businesses optimize their customer journey from visitors to paying customers.

## 🎯 Objective
- Analyze user flow across funnel stages (Visitor → Lead → Customer)
- Identify major drop-off points in the funnel
- Evaluate conversion performance over time
- Provide actionable recommendations to improve conversion rates

## 🛠️ Tools Used
- Power BI
- Excel

## 📁 Dataset
- E-commerce User Behavior Dataset (Oct–Nov 2019)

## 📈 Key Metrics
- Total Visitors
- Total Leads (Add to Cart)
- Total Customers (Purchases)
- Conversion Rate (%)
- Lead Conversion Rate (%)

## 📊 Analysis Performed
- Funnel analysis (Visitors → Leads → Customers)
- Conversion rate calculation
- Drop-off identification at each stage
- Time-based conversion trend analysis

## 🔍 Key Insights
- Significant drop-off occurs between the visitor and lead stage, indicating low engagement.
- Conversion from leads to customers is relatively low, suggesting friction in the purchase process.
- A large portion of users browse products but do not proceed to checkout.
- Overall funnel efficiency is low, highlighting opportunities for optimization.

## 💡 Recommendations
- Improve product pages and user experience to increase engagement.
- Simplify the checkout process to reduce abandonment.
- Implement retargeting strategies for users who add items to cart but do not purchase.
- Optimize marketing efforts towards high-converting user segments.
